# RPD RAGAS 三指标报告（M1）

> 用 `consult_company_knowledge` 底层的 `knowledge_agent_graph` 生成三元组，跑 RAGAS 三指标（faithfulness / answer_relevancy / context_precision）。

## 1. 结果

全量 30 问（报告 `eval_external/results/ragas_20261026_112808Z.json`）：

| 指标 | 分数 | 说明 |
|---|---|---|
| faithfulness（忠实度） | 0.9402 | 回答陈述被检索上下文支持的比例 |
| answer_relevancy（回答相关性） | 0.7511 | 回答与问题的相关度 |
| context_precision（上下文精度，**近似替代**旧 context_relevancy） | 0.9565 | 检索上下文与问题相关的比例 |

- 10 问验证集（`ragas_20261026_111815Z.json`）：faithfulness 0.8958 / answer_relevancy 0.7239 / context_precision 0.8810。
- 三元组（question / retrieved_contexts / response）见同目录 `ragas_triplets_*.json`。
- **NaN 实情**：30 问中 faithfulness 有 **8/30**、context_precision 有 **7/30** 因 QWEN 判官超时记为 NaN；上表均值是剔除 NaN 后的结果（有效样本分别 22、23）。`per_sample` 保留 NaN 原样。

## 2. 方法

- **问题集**：`eval_external/ragas_questions.json`，30 条合成问题，覆盖手册全部 10 段（每段 3 问）。
- **三元组生成**：对每问调用 `knowledge_agent_graph.ainvoke({"query", "tenant_id"})`，取 evidence 文本作为 `retrieved_contexts`、合成回答作为 `response`（hybrid 检索 + DeepSeek 生成）。
- **评分**：RAGAS 0.2.15，judge 复用 `QWEN_JUDGE`（`qwen3.7-max`，Dashscope 兼容），embedding 复用 `DASHSCOPE`。
- **指标映射**：RPD 原计划的 `context_relevancy` 在 RAGAS 0.2.x 已不存在；本文用 `LLMContextPrecisionWithoutReference` 作**近似替代**（同为「检索上下文与问题相关度」），二者并非严格等价，引用时需注明。

## 3. 复现

见 `docs/ragas-setup-20261026.md`（依赖与补丁），运行：

```powershell
# 隔离环境变量注入后：
python eval_external/ragas_eval.py --apply --allow-external-llm
```

## 4. 口径与限制

- 合成租户 + 30 条合成问题，只反映当前知识子 Agent 在合成语料上的 RAG 质量，不代表线上。
- faithfulness / context_precision 用 LLM-as-judge，存在判官本身波动；answer_relevancy 依赖 embedding 相似度。
- 与 M2 检索评测（hit@1/recall@3/MRR@3）口径不同：M2 只看检索命中，M1 看生成 + 检索的整体 RAG 质量。
